Quick Start

  1. Download and open Moon Injector.
  2. Wait for it to detect Roblox (or specify PID).
  3. Click Inject – the internal pipe server starts.
  4. Send Lua scripts to \\.\pipe\MoonPipe_<PID>.

Pipe Protocol

1. Connect to the named pipe.
2. Write your Lua script as a single line (or with \n).
3. Read back "OK" on success or an error message.

Example (PowerShell):
$p="12345"; $pipe=New-Object System.IO.Pipes.NamedPipeClientStream(".","MoonPipe_$p",[System.IO.Pipes.PipeDirection]::InOut); $pipe.Connect(3000); $w=New-Object System.IO.StreamWriter($pipe); $w.WriteLine("print('hello')"); $pipe.Close()
